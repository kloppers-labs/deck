# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What deck is

A Bubble Tea TUI "command center" with four tabs — **Files**, **Git**, **Run**, **HTTP** — over the current working directory. The module is `github.com/kloppers-labs/deck`. `cli.go` runs first: `deck [dir]` changes into `dir` (`deck -- <dir>` for a directory named like a subcommand), the agent subcommands `open`/`review`/`diff`/`where`/`ls`/`launch`/`guide` run in `cli_agent.go` without starting the TUI (see Agent support below), and `--version` (the `main.version` ldflag set by GoReleaser, else the module version from build info, else `dev`) and `--help` print and exit without starting the TUI. `main.go` then loads config, maps `mouse` to program options (`hover` → all-motion, `click` → cell-motion, always `WithReportFocus`) builds one `lsp.Manager` from `app.LSPConfig(cfg.LSP)` (wrapped in `files.NewLSPAdapter` and passed to `app.New(cfg, warnings, nav)`; `nil` when `lsp.enabled = false`) and boots the root model in `internal/app`. After `p.Run()` returns, `main` calls `Model.StopAll` on the final model as a backstop so no task outlives deck, and a deferred `app.ShutdownLSP(mgr, 3s)` stops every language server (shutdown/exit, then a process-group kill). Everything else lives under `internal/`.

Deck does not call any AI API directly; agents drive deck from outside (Agent support below). The only AI feature is the Git tab's `ctrl+g` commit-message helper (`internal/aicommit`), which shells out to the user's already-authenticated `claude`, `codex`, or `crush` CLI (`mods` is a deprecated alias for `crush`). Editing is delegated to `micro` (configurable) via `tea.ExecProcess`, which suspends the TUI for the duration of the child process.

## Common commands

```bash
go build ./...                       # build
go test ./...                        # run all tests
go test ./internal/git -run TestX    # single test
go test -race ./...                  # race detector
go run .                             # launch the TUI
```

Releases: pushing a `vX.Y.Z` tag runs `.github/workflows/release.yml`, where GoReleaser (`.goreleaser.yaml`) builds darwin/linux × amd64/arm64 (Windows is unsupported: Unix process groups), publishes archives, `.deb`/`.rpm`/`.apk` and checksums, and pushes the Homebrew cask to `kloppers-labs/homebrew-tap` over SSH with the `HOMEBREW_TAP_DEPLOY_KEY` secret. `install.sh` installs the latest release from those archives. CI (`ci.yml`) runs gofmt, vet and `go test -race` on macOS and Linux, plus a GoReleaser snapshot build.

## Configuration (`internal/config`)

`config.Load() (Config, []Warning)` reads `$XDG_CONFIG_HOME/deck/config.toml` (falling back to `~/.config/deck/config.toml`), then a project-local `.deck.toml` found by walking up from the cwd to the directory holding `.git` (or the cwd itself). Later files override scalars and **append** `tasks`. The whole schema (spec §12) is defined up front — `Files`, `Viewer`, `LSP{Enabled, Prestart, RequestTimeoutMS, OfferInstall, Servers}`, `Git{ConfirmCommit, ReviewBase}`, `Agent{Enabled, Launch, Watch, WatchMS, Claude}`, `Task{Name, Cmd, Dir, Env, Kind}`, plus `mouse`, `editor_return`, `micro_bundle`, `micro_lsp` — so later work only reads config, it never adds fields.

- Defaults live only in `Default()`. Files are decoded on top of it, so omitted booleans keep their defaults and an explicit `false` sticks; afterwards zero strings/numbers and nil slices/maps are filled from `Default()`.
- Nothing is fatal: a decode error, an unknown key (with a "did you mean" suggestion from the schema) or an invalid enum value (`mouse`, `editor_return`, `micro_lsp`, `files.icons`, `agent.launch`; `agent.watch_ms` below 250 is clamped with a warning) becomes a `Warning`. `main` passes the warnings to `app.New(cfg, warnings, nav)`, and `Init` shows them as one toast.
- `lsp.servers` is empty by default; built-in server definitions belong to the lsp package. `LSPServer.Enabled` is a `*bool` so an omitted `enabled` means on.
- `lsp.offer_install` (default `true`) lets the Files tab offer to install a missing language server (see `internal/files` install glue); `false` keeps only the hint.
- Configured `tasks` are always shown; tasks detected by the Run pane are merged after them (see `internal/runner`).

## Architecture

### Root model owns the chrome (`internal/app`)

`Model` holds one value of each pane type and an `active tab`, plus the toast queue, help-modal state and mouse state. `app.go` is the model and routing, `mouse.go` the mouse translation, `help.go` the help modal.

**Routing contract (`ui.Routed`).** Every async or cross-tab message implements `RouteTo() ui.Dest` (`DestApp`, `DestFiles`, `DestGit`, `DestRun`, `DestHTTP`). `app.Update` delivers any `ui.Routed` message to its destination whichever tab is active — today the Git pane's async results (`git.RefreshMsg`, `StatusLoadedMsg`, `DiffLoadedMsg`, `CommitMsgReady` and its internal op/commit/branch/log results), `runner.OutputMsg`/`ExitMsg`/`DetectedMsg`, `httpc.RespMsg`/`LoadRequestMsg`, the viewer's `DocLoadedMsg`/`DocHighlightedMsg`/`MarkdownRenderedMsg`/`LocationsMsg`/`HoverMsg`/`SymbolsMsg`/`GotoMsg`/`ChooseMsg`/`OutlineMsg`/`JumpedMsg` and `files.LSPEventMsg`/`ReloadMsg`/`RevealMsg`/`InvalidateMsg`/`StatMsg`/`BadgesMsg`/`RefreshBadgesMsg`/`FinderIndexMsg`/`GrepChunkMsg`/`GrepDoneMsg` and the picker's messages (→ Files), `git.ReviewMsg` and `files.ReloadFileMsg`, and the app-bound `ui.ToastMsg`, `ui.FocusTabMsg` (switch to the tab owning a `Dest`), `control.RequestMsg` (agent navigation), `ui.MentionMsg` (`@`: to the Claude bridge, else `@rel#Lx-y` on the clipboard), `ui.ShowFileMsg` (a diff line's `enter`: Files tab via `files.AgentOpen`), `ide.ClientsMsg` (the `✦ Claude` badge) and `editor.ResyncMsg` (a quiet micro bundle sync, sent after a language server is installed). A message that also implements `ui.Broadcast` (`AlsoTo() []Dest`) is delivered to those destinations too: `git.StatusLoadedMsg` reaches Files as well, for the tree's git badges. A new async message needs only a `RouteTo` method, never a new `case` in `app.Update`. Other app-level cases: `editor.OpenMsg{Target}` (from the viewer, the Git tab's `e` and a Run problem's `enter`; `editor.Open(t)` builds the command) is handled in `internal/app/editor.go`: `editor.Launch(cfg.Editor, target, opts)` returns the command and a `Mode` — `Suspend` runs it through `tea.ExecProcess`, `Detach` (VS Code family without `-w`, zed/subl, JetBrains) starts it in the background with an `opened in …` toast (both cases are matched before the `ui.Routed` case); `git.GenCommitMsgRequest` runs `aicommit.Generate` on `Repo.StagedDiff` (90 s timeout, cancellable through `Ctx`); `editorClosedMsg` carries the bridge state read by the exec callback (`editor.ReadState`, then the temp file is removed) and returns `git.Refresh`, `files.RevealMsg` at `editor.ReturnTarget` (`editor_return = "follow"` goes where micro ended if it is under the cwd, `"origin"` back to where deck launched it; `files.ReloadCurrent` when there is no target), `files.InvalidateMsg{Saved}` for files saved in micro, and an error toast if the editor failed; `editor.SyncedMsg` (from the startup sync) becomes one warning toast when `Notify` is set; `WindowSizeMsg` also returns `files.ResizeCmd()` so rendered markdown re-wraps; `spinner.TickMsg` fans out to every pane with a spinner. `Init` sends `files.Init`, the first `git.Refresh`, `run.Init` (background task detection) `files.ListenLSP` (the re-arming language-server event listener), the prestart cmd (`Prestart(cwd)`: csharp-ls warms up only when the cwd project has a `.sln`/`.slnx`; other servers start lazily on the first request) and, when `micro_bundle` is on and the editor is micro, `editor.SyncCmd` (micro runtime sync), so the status bar's branch and the repo-root project name arrive asynchronously. Switching to a tab runs `focusCmd`: `git.Refresh` for Git, `files.RefreshBadges` for Files. `badges.go` holds `gitBadges`, the Files tab's `BadgeSource` (passed with `files.New(…).WithBadges`): `OpenRepo` + `StatusSnapshot(ctx, includeIgnored=true)` → `files.BadgesFromEntries`. Keys, mouse events and everything else go to the active pane after global handling.

**Frame contract.** `SetSize(w, h)` is a pane's **outer** box, borders included, and `View()` must return exactly `h` rows of at most `w` columns — panes end `View` with `ui.Fit`. The body is `h - 5` (tab bar 3, status 1, footer 1) and `app.View` fits every section again as a backstop. Below 60×16 the frame is a centred `terminal too small` notice. `layout_test.go` checks every tab (with and without help) at 60×16, 80×24, 120×40 and 200×50 using long-name fixtures.

**Capture rules.** A pane's `Capturing()` is true only while text is being typed or a modal is open (filter, commit box, viewer `/`/`:` prompt or pending chord, HTTP insert mode or `.http` sidebar, Run task filter or log search, branch picker, a y/n prompt (including the Files install offer), an open picker, a Files rename/new prompt or a pending `y` chord); reading, scrolling and selecting never capture. While capturing, single-letter globals (`q`, `?`, `1`–`4`) are suppressed and the footer shows `esc normal` instead of `q`/`?`. The footer's global tail always stays visible; the pane's hints are truncated to the space left. Capture-proof keys are checked first: `ctrl+c`, `tab`/`shift+tab`, `alt+1`…`alt+4`, `F1`, `alt+m`, and `alt+j` while an agent jump is held.

**Mouse.** `app.mouse` drops motion events on the same cell as the last one, handles tab-bar clicks with the pure `tabHitTest`, ignores the status and footer rows, and forwards body events to the active pane with `Y` reduced by the tab-bar height; containers keep translating into child-local coordinates (`ui.Rect.Local`). `alt+m` toggles reporting at runtime (`tea.DisableMouse` / re-enable per `cfg.Mouse`) and the footer shows `mouse off`. `ui.ClickTracker` turns presses into click counts (double-click = same cell within 400 ms).

**Toasts and status bar.** `ui.ToastMsg{Level, Text, TTL}` (or `ui.Toast(level, text)`) from anywhere shows on the right of the status bar; the newest live toast wins and each expires through a `tea.Tick`. The pure `statusLine(left, right, w)` lays out project · branch · dirty · running on the left and the LSP badges (`lsp.go`'s `lspBadge`: `C# ⠋ Loading Foo.sln 42% (18s)` while starting/indexing, `C# ●` ready, `C# ✗` failed or exited; from `files.LSPStatus()`) and the toast on the right, truncating the left side first.

**Quit and re-run (`quit.go`).** `q`/`ctrl+c` quit at once when no task runs; otherwise a modal asks `N tasks running (a, b): quit and stop them? [y/N]`. `y` runs `run.StopAllCmd` (signal now, wait up to 5 s off the UI goroutine, then `tea.QuitMsg`), any other key dismisses it, and a second `ctrl+c` force-quits (main's backstop still stops the tasks). `ctrl+r` (gated by capture) re-runs the last Run task from any tab without switching. The Run tab badge shows the running count and a red `✗N` for failed tasks.

**Help.** `?`/`F1` opens a centred modal composited with `ui.Overlay` over the dimmed body (`ui.Dimmed`), grouped Global / active tab / Mouse and built from the same `key.Binding` values the panes export. It is modal (only `ctrl+c` escapes it), scrolls with `j`/`k`/wheel, filters with `/`, and closes with `esc`/`?`/`F1`/`q`.

When adding a new tab: add to the `tab` enum, `tabNames`, `tabDests`, the `Model` struct, `New`, `resize`, `capturing`, `routeTo`, `paneView`, `paneBindings`, the `globalKey` switches and `ui.Keys` (`N` and `alt+N`), plus a `ui.Dest` for it.

### Each pane is its own package

Panes are value types (so the root model can copy them in/out of `Update` cheaply). Each exports `New…`, `SetSize`, `Update(msg) (Self, tea.Cmd)`, `View`, and usually a `Capturing() bool`.

- `internal/files` — the Files tab container: tree sidebar, `viewer.Model` and optional info panel, each in its own bordered box (`layout.go`: `ComputeLayout` tiles the width; the tree is `files.sidebar_width`, capped at 40%, hidden by `ctrl+b` and automatically below 90 columns; the 24-column info panel drops out when the viewer would get under 30). `New(dir, cfg)` lists only the root; `Init` loads the first selection and the first badges. The focused region gets the `ui.PaneActive` border.
  - `tree.go`: `Node`/`Tree`. Children load on first expand; a directory over 5k entries (`bigDirEntries`) loads through a command (`dirLoadedMsg`). `Flatten(root, hide)` gives the visible rows; the selection is tracked by path so it survives reloads. `Reveal(path)` reroots if needed, expands (and loads) ancestors and selects the path even inside hidden directories (`HidePolicy.Keep`). Rerooting: `-` up (the old root is grafted back with its expansion and selected), `=` the selected directory, `~` the launch root. `Reload` re-reads expanded directories in place keeping node identity. Rows are cut to the sidebar with `ansi.Truncate(…, "…")` and keep the badge in the last column; broken symlinks show red with `→ target`.
  - `hide.go` (`bin obj .git node_modules .vs .idea TestResults` by default from config; `.` dotfiles, `I` gitignored + hidden names), `sort.go` (`s`: name → modified → size → extension, directories first), `icons.go` (`files.icons` unicode/nerd/none).
  - `gitbadges.go`: `Badge` (conflict > deleted > modified > added/untracked > renamed), `BadgeSource func(ctx, root) (Badges, error)` injected with `WithBadges`, `BadgesFromEntries`, pure `Aggregate` (each directory carries its strongest descendant) and `LogicalTop` (maps git's symlink-resolved top level onto the launch path's spelling). Badges refresh on Files-tab focus (`RefreshBadgesMsg`), `tea.FocusMsg`, `ReloadMsg`/`RevealMsg` (editor close) and `R`; a routed `git.StatusLoadedMsg` updates statuses directly and keeps the last ignored set.
  - `meta.go`: `StatCmd(path, seq, cache)` → `StatMsg` (Lstat, line count up to 10 MB, directory walk capped at 20k entries / 300 ms and marked partial, `.csproj`/`.sln` extras), cached by path+mtime; pure `FormatMeta(meta, badge, w, now)` breaks ` · ` groups onto their own lines when narrow. Resting the mouse on a tree row for 400 ms (`hoverDueMsg{seq}`; any other row, key or leaving the tree bumps the seq) shows a tooltip placed with `viewer.PlacePopup` and composed with `ui.Overlay`; `i` toggles the info panel for the selection.
  - `dircard.go`: selecting a directory shows a card through `viewer.OpenVirtual` — counts, the first 200 visible children with badges and sizes, and a project card per `.csproj`/`.fsproj`/`.vbproj` (`ParseCsproj`: Sdk, TargetFramework(s), OutputType, package/project reference counts) and a project list per `.sln`/`.slnx` (`ParseSln`/`ParseSlnx`).
  - Keys: in the tree `j`/`k`/`g`/`G`/`ctrl+d`/`ctrl+u`, `enter` toggles a directory or focuses the viewer on a file, `l`/→ expands (then steps into it), `h`/← collapses or goes to the parent, `<`/`>` resize, `e` opens the editor at the viewer's cursor (line 1 when the file is not open), `x` on a `.http` file emits `httpc.LoadRequestMsg`. In the viewer `esc` first closes its prompt/search, then returns to the tree; `e` on a directory card does nothing. `ctrl+b` and `i` work from both regions. The viewer `Spot` is remembered per path. Mouse: the divider drags (press, motion with the button held, release), the tree wheel scrolls without moving the selection, a click selects (on a directory's marker it toggles; double-click opens), motion drives the hover, and events over the viewer are translated to viewer-local coordinates (`ViewerInner`). `ListTop` is the first tree row's local Y. `ReloadMsg` (from `ReloadCurrent`) reloads the tree, the badges and the open file in place; `RevealMsg{Target}` (editor return) reloads the tree and the badges, then reveals a file in the tree and opens it at the target position. `SelectedPath()`/`ViewerLoc()` are the cross-package accessors.
  - Picker glue (`pick.go`): `ctrl+p` (find file) and `ctrl+f` (grep) open a `picker.Model` from either region, drawn with `ui.Overlay` across the bottom of the pane (`pickerRect`) so the viewer rows above stay visible. Moving the selection peeks (opens the item in the viewer without touching the tree); `esc` restores the viewer to where the picker opened (`pickOrigin`); `enter` pushes that origin onto the `history` jump list (`*viewer.History`, shared across copies), reveals the file in the tree and opens it.
  - LSP glue. `lspadapter.go`: `NewLSPAdapter(*lsp.Manager)` implements `files.LSP` (`viewer.Navigator` + `Reload`, `NextEvent`, `Logs`) and `app.LSP` (+ `Prestart`, `Shutdown`) over a small `lspBackend` seam; it converts rune columns to the server's negotiated encoding and back (reading the target files, or the cached text of a `csharp:/…` metadata document), maps `lsp.StatusEvent` to `viewer.ServerStatus` (`C#`/`Go`/`TS`/`Py`/`Rust`/`Sh`/`Lua`/`YAML`/`JSON` labels, the spec's `Language` and the `Install` argv), forwards `Install` to the manager, converts diagnostics, never starts a server just to `Reload`, and sends workspace symbols to the file's server or else the first running one. `lspevents.go`: `ListenLSP` wraps each event in `LSPEventMsg` (statuses → `LSPStatus()` for the status bar with a 500 ms tick while loading, diagnostics → `viewer.SetDiagnostics`, logs → the `L` log picker, `showMessage` → toast); `InvalidateMsg` (editor saves) re-sends saved documents. `nav.go`: `GotoMsg` pushes the origin onto the history and `openAt`s the target (in place when already open and selected, `OpenURI` for virtual documents, no tree reveal outside the launch root, otherwise `show` reveals it); `ChooseMsg` (several definitions, references) opens a picker grouped by file with the current file first, rows `relpath:line:col  text`, peeking as the selection moves; `OutlineMsg` lists symbols indented with kind glyphs (markdown outlines switch to the raw source, and `esc` switches back); `ctrl+t` is a Live workspace-symbol picker debounced 150 ms (`wsDueMsg`/`wsResultMsg` with a seq, `wsDebounce` is the seam); `ctrl+o`/`alt+←`/mouse-back and `ctrl+]`/`alt+→`/mouse-forward walk the history across files (`JumpedMsg` and file switches from the tree also push); `L` in the tree opens the LSP log. `install.go`: when a `viewer.DocLoadedMsg` or a failed `ServerStatus` event leaves the open file's server `ServerFailed` with an `Install` argv, the pure `offerFor(status, noOffer, lookPath)` offers it only if `Install[0]` is on `PATH` (`installerLookPath` seam), the server isn't in the session's `noOffer` set, `lsp.offer_install` is on and the LSP implements `files.Installer`. The offer is a warn-bordered box overlaid at the bottom of the pane (`Python language server isn't installed. Install pyright now? (npm install --global pyright)  y/n`) and captures: `y` installs, `n`/`esc` declines for the session, any other key closes it until the next file. Installing upserts a `ServerStarting` status titled `installing <pkg>` (the status bar spinner) and runs `Installer.Install` in a command with a 5-minute timeout; `installDoneMsg` toasts success (and returns `editor.ResyncMsg` and reloads the open file so the server starts) or the error with the output's last two lines, and restores the failed status. An installed, declined or failed server is not offered again this session.
  - `finder.go`: the index is built on first `ctrl+p` (`FinderIndexMsg`), never at startup, from `fd` (or `fdfind`), else `git ls-files -co --exclude-standard -z`, else a `WalkDir` honouring the hide names (`buildIndex` with an injectable `indexEnv`; `finderEnv` is the test seam), capped at 200k paths. Focus, `R`/reloads, editor return and file ops mark it stale; the next open shows the old index and rebuilds in the background. `matchFiles` ranks a fuzzy match inside the file name above one that needs directories; `file.cs:120[:7]` (`splitLineSuffix`) filters by the name and jumps to the line.
  - `grep.go`: a Live picker; each query change bumps `grep.qseq` and arms a 200 ms `grepDueMsg`, and only the latest starts a search. `startGrep` runs `runGrep` (`rg --json`, else `git grep -n --column -I -z`, else a capped walk; `runGrep`/`grepDebounce` are the test seams) under a cancellable context and streams `GrepChunkMsg`/`GrepDoneMsg` tagged with `grep.seq` through a channel read one `next()` Cmd at a time, like the runner; stale chunks are dropped and a new search or closing the picker cancels the old one. `parseRGJSON`/`parseGitGrep` are pure and convert byte offsets to rune columns. Hits are grouped by file. `alt+r` regex (default literal), `alt+c` case-sensitive (default smart-case), `alt+g` reads the query's last word as a file glob.
  - File operations (tree only): `a` new (inside the selected directory or beside the selected file; a trailing `/` makes a directory; parents are created), `r` rename (cursor before the extension), `D` trash after a `y/N` confirm (`Trash{Dir, Cmd}`: `~/.Trash` on macOS, else a `trash` binary, else refuse; `trashFor` is the seam), `yy`/`yY` copy the relative/absolute path over OSC52 (`clipboard.go`, `clipboardOut` seam; the pending `y` captures), `o` reveals in Finder (`open -R`, `revealInOS` seam), `!` runs `$SHELL` in that directory through `tea.ExecProcess`. `prompt.go` draws the inline prompt on the tree's last row; ops run as commands returning `opDoneMsg`, after which the tree reloads and selects the result (or keeps the row index after a trash). Pure helpers in `ops.go`: `CreatePath`, `RenamePath`, `renameCursor`.
- `internal/viewer` — the read-only code viewer. `Load`/`LoadCmd` stat, read the whole file (`io.ReadAll` over a 20 MB `LimitReader`, so no short reads; larger files are `Truncated` with a header banner), detect binaries and split into `Raw` (`\r` stripped; editor/LSP columns), `Plain` (tabs expanded, control bytes → U+FFFD one-for-one) and `Styled` (filled later). A 16-entry LRU `Cache` keyed by path+mtime+size+theme+tab width is shared by all copies of the model. Highlighting runs as a command after the plain text is shown: the whole file is tokenised once (multi-line comments stay correct) and token types map to cached SGR prefixes per (theme, colour profile; truecolour only when `COLORTERM` says so); files over `viewer.max_highlight_bytes` or 50k lines are highlighted in 2000-line chunks around the viewport, and lines over 4000 columns stay plain. `lexmap.go` maps .NET extensions (`.csproj`/`.props`/`.targets`/`.resx`/`.xaml`/`.slnx` → XML, `.razor`/`.cshtml` → HTML, `.sln`/`.editorconfig` → INI) before chroma's own matching. Every request carries a `gen` from a shared atomic counter; stale loads are dropped and superseded highlights skip their work. Markdown renders through glamour by default (renderer cached per style and width, mermaid output cached per block) and `m` toggles the raw source. `View` is O(visible rows): `relayout` computes the rows in `Update`, each row is cut with `ansi.Cut` and only rows with a cursor or search hit go through the pure `Paint(styled, spans)`. Pure helpers, each table-tested: `geometry.go` (`DispCol`/`RuneCol`, `ScreenToDoc`/`DocToScreen` with gutter, offset and wrap, `EnsureVisible` with 3-row/8-column scroll-off), `words.go`, `search.go` (smart-case, literal or regex, wrap-around), `chord.go` (`g`/`z`/`]`/`[` prefixes, no timers), `history.go` (jump list, owned by the Files container), `spans.go`, `popup.go` (`PlacePopup(anchor, w, h, bounds)`: below, else above, clamped). `virtual.go`: `NewVirtualDocument(path, plain, styled)` is a pre-styled document with no gutter (directory cards) and `OpenVirtual(path, at, build)` builds it in a command under the normal load generation. Keys follow spec §8.3 (no digit counts — `1`–`4` stay tab keys); `e` emits `editor.OpenMsg` at the cursor's line, column and top; `y`/`Y` copy over OSC52 (`clipboardOut` is the test seam). `Capturing()` is true only while the `/` or `:` prompt is open or a chord is pending. LSP features (`navigator.go`, `lspcmd.go`, `hover.go`, `symbols.go`, `diagnostics.go`) go through the `Navigator` interface (set with `Options.Navigator`/`SetNavigator`; nil means no LSP) with viewer-side `Loc`/`Location`/`Hover`/`Symbol`/`ServerStatus`/`Diagnostic` types in rune columns. Each request is a cmd with a per-kind seq (stale results or another path are dropped) and the request timeout; a new hover cancels the previous one. `gd`/`F12`/ctrl+click/double-click/right-click (gestures from `viewer.goto_click`) request the definition, `gi`/`gy` implementation/type definition, `gr`/alt+click references: one result emits `GotoMsg`, several (or any references) `ChooseMsg`, for the container to act on. `K` shows the hover when the file has a server (otherwise it still scrolls 10 lines up), and resting the mouse on a word for `hover_delay_ms` does too (the dwell tick restarts only when the word under the mouse changes); the popup (≤80×16, glamour-rendered and cached, placed with `PlacePopup`, target underlined) scrolls with `ctrl+j`/`ctrl+k` or the wheel and closes on any other key, `esc`, a scroll, or 300 ms after the mouse leaves. `o` emits `OutlineMsg` (document symbols, or `MarkdownOutline` headings for markdown). Document symbols load with each document and drive the breadcrumb header (`Breadcrumb`). Diagnostics show as `●`/`▲` in the gutter, `]d`/`[d` jump with wrap-around, and the footer shows the cursor line's message. Without a server, the first request toasts `no language server for .cs — csharp-ls not found` and later ones show it in the footer; empty results while a server loads toast `C#: still loading … (Ns) — results may be incomplete`. `OpenURI` shows a server-provided read-only document (`[metadata] System.String`), `JumpTo` moves within the open one, and `gg`/`G`/`:N` jumps longer than a screen emit `JumpedMsg`. The wheel scrolls `viewer.scroll_lines`, ramping to 3× for events under 40 ms apart (the clock is injectable); shift+wheel scrolls horizontally; a click places the cursor. `BenchmarkViewerView` (200 rows over 50k lines) runs in well under 1 ms.
- `internal/editor` — launching editors and deck's bundled micro runtime (spec §7). `Target{Path, Line, Col, Top}` (1-based, 0 = unset) and `OpenMsg{Target}` (→ app).
  - `profiles.go`: `Args(editor, target)` is the pure per-editor table (micro/emacs/kak `+L:C`, vim/nvim `+call cursor(L,C)`, hx/zed/subl `file:L:C`, code family `-g file:L:C`, nano `+L,C`, JetBrains `--line L --column C`, `{file}`/`{line}`/`{col}` templates, unknown → path only; `Line == 0` → no position). `Launch` wraps it into an `*exec.Cmd`.

- `internal/git` — the Git tab and the git CLI layer. `exec.go`'s `runGit(ctx, dir, args...)` keeps stdout and stderr apart (so CRLF warnings never reach a diff), forces `GIT_TERMINAL_PROMPT=0`, `GIT_OPTIONAL_LOCKS=0`, `LC_ALL=C`, and applies a 10 s timeout unless the context already has a deadline (remote ops use 120 s). `OpenRepo(ctx, cwd)` resolves `Repo{Top, GitDir}` once; every `Repo` method runs as `git -C Top` with root-relative paths, so launching from a subdirectory works. `Repo.StatusSnapshot(ctx, includeIgnored)` parses `status --porcelain=v2 --branch -z` with the pure `ParseStatusV2` into `Snapshot{Branch, Upstream, Ahead, Behind, Initial, Entries}`; `Items` groups entries into Staged / Unstaged / Untracked / Conflicts sections (an `MM` file is in both Staged and Unstaged, each with its own diff; untracked files diff with `--no-index` against `/dev/null`).
  - The pane (`pane.go`, `diff.go`, `commit.go`, `branches.go`, `loglist.go`, `view.go`) never calls git synchronously: `NewPane(Options{Theme, CommitAI, ConfirmCommit, Dir})` runs nothing, `RefreshMsg` returns a load command producing `StatusLoadedMsg{Seq}` (stale seqs are dropped and the last state stays visible behind a spinner), cursor moves debounce the diff load by 50 ms (`diffDueMsg`), and diffs are cached per path, section, index mtime and work-tree file stamp, capped at 200 KB with a `… N more lines · e open` footer. After a reload the cursor stays on the same entry, or on its neighbour in the same section when the entry moved.
  - Focus is explicit: in the list `j`/`k` only move the cursor; `enter`/`→`/a click on the right focuses the diff, where `j`/`k`/`ctrl+d/u`/`g`/`G` scroll and `esc`/`h` return. `space` stages or unstages per section, `a`/`A` stage/unstage all, `X` discards after a y/n prompt, `e` emits `editor.OpenMsg` at `firstHunkLine` of the shown diff, `f`/`p`/`P` fetch `--prune` / pull `--ff-only` / push (setting the upstream when there is none) as one busy op at a time, `b` opens the branch picker (cursor on the current branch, `n` new via `switch -c`, `D` delete with a prompt, `enter` uses `switch`), `l` swaps the list for a `bubbles/list` log of 200 commits (`enter` shows `show --stat -p`).
  - The commit box is a `bubbles/textarea` (subject counter turns red past 72): `ctrl+s` commits (through the huh confirm when `git.confirm_commit`), `alt+a` toggles amend and prefills the last message, `ctrl+g` asks for an AI message — the box shows a spinner, `esc` cancels, a failure keeps the typed text, reports it in the status line and raises an error toast. Commits are async and pass the message on stdin. `Branch()` (with `↑a ↓b`), `DirtyCount()` and `Top()` feed the status bar.
- `internal/aicommit` — no UI. `BuildArgs` maps a backend to its CLI invocation; `Generate(ctx, backend, model, diff)` pipes the diff (capped at 60 KB on a line boundary) to the CLI on **stdin**, never argv, captures stderr into the error, and strips Markdown fences; `Available` checks `PATH`. Tests swap the package-level `execCommand`/`lookPath` seams for a helper process.
- `internal/runner` — Run tab.
  - `procgroup.go`: each task runs under `sh -c` in its own process group (`Setpgid`), in `Task.Dir` (relative to the root) with `Task.Env` plus `FORCE_COLOR`/`CLICOLOR_FORCE`/`DOTNET_SYSTEM_CONSOLE_ALLOW_ANSI_COLOR_REDIRECTION`. Stopping cancels the context: `cmd.Cancel` sends SIGTERM to the group, a reaper sends SIGKILL to whatever is left after `killDelay` (3 s), and `proc.done` closes only once the group is gone. Output is split on `\n`, `\r\n` and bare `\r` into `chunk`s; a reader that would block drops lines once stopped so a stop never deadlocks.
  - `logbuf.go`: capped line buffer with stable absolute line numbers; a `\r`-terminated chunk is overwritten by the next one. `logview.go`: per-task scroll/follow (`↓ N new`), smart-case search, wrap, and problems; it renders only the visible rows.
  - `problems.go`: pure matchers for msbuild/dotnet and tsc (`path(l,c): error CODE: msg`), tsc `--pretty` and Go (`file.go:l:c:`). Paths resolve against the task dir; `enter` on a problem emits `editor.OpenMsg`.
  - `runner.go`/`dotnet.go`: `Init` detects tasks in the background (`DetectedMsg`): Go, npm/pnpm/yarn/bun scripts (from the lockfile), Angular, .NET (walks 3 levels skipping `bin`/`obj`/`node_modules`/`.git`; build/test the root `.sln`/`.slnx`, run/watch each Web or Exe project), Python, Cargo, Gemfile, Makefile/justfile. Capped sources report `+N more`. Detected tasks whose name or command is already configured are dropped; the rest show as `auto`.
  - `pane.go`: list ↔ log focus (`l`/click into the log, `esc`/`h` back), `StopAll(timeout)`/`StopAllCmd`, `Rerun`, `RunningNames`, `FailedCount`; a failed exit raises an error toast and the header shows `exit N`.
- `internal/httpc` — REST client. `httpc.go` holds pure helpers: `buildRequest` (loopback hosts default to `http://`, a JSON body gets an auto `Content-Type` shown greyed), header parsing/formatting and Chroma highlighting. `pane.go` has normal mode (not capturing: `j`/`k`/`g`/`G`/wheel scroll the response, `[`/`]` Body/Headers, `i`/`enter`/click to edit) and insert mode (`esc` back); `ctrl+s` sends, `esc` cancels an in-flight request (requests carry a `seq`, so a late reply is ignored), latency includes reading the body, and bodies over 1 MiB show `truncated at 1 MiB`. `httpfile.go` parses `.http` files (`###`, `# @name`, `@var = value`, `{{var}}`, `{{$guid}}`, `{{$timestamp}}`, `{{$dotenv KEY}}`, `{{$processEnv KEY}}`); variables resolve at send time, file variables over the environment. `env.go` loads the nearest `http-client.env.json` (+ `.private`, `$shared`); `ctrl+e` cycles environments. `sidebar.go`: `ctrl+o` lists requests from `**/*.http` (depth 4, 100 files), and `LoadRequestMsg` loads a request and focuses the tab.

- `internal/ui/picker` — the shared fuzzy overlay (`Item{Title, Detail, Path, Line, Col, Group, Highlight}`). Filtering pickers rank with `sahilm/fuzzy` on `Title` (or an `Options.Match` func) and highlight matched runes; above `AsyncThreshold` (50k) items matching runs in a command guarded by a seq. `Live` pickers never filter: they report `QueryMsg` and the owner `SetItems`/`Append`s results. - `internal/presence` — `Store` (mutex, shared by pointer) holding a `Snapshot` of where the user is: tab, file, 1-based line/col (runes), `Sel` (`EndLine` inclusive, `EndCol` exclusive), `SelText` (16 KiB cap), markdown `Section`, `Visible`, `Git{Mode, Base, Side}`, `Recent`, `Seq`. `Publish` ignores `Seq` and bumps it only on a change; `Subscribe` gives a coalescing channel; diagnostics per path for the IDE bridge.
- `internal/control` — the agent socket. `Dir` is `$XDG_RUNTIME_DIR/deck`, else `${XDG_STATE_HOME:-~/.local/state}/deck/run`, never `TMPDIR` (agent sandboxes move it); clients search every candidate (`Dirs`/`ListAll`). Each deck listens on `<dir>/<pid>.sock` (0600, dir 0700; `SocketPath` checks the 103-byte limit) with a `<pid>.json` sidecar `Instance{PID, Root (worktree top), Cwd, Version, Socket, Started, Focused}`; `List` sweeps dead pids and refusing sockets; pure `Pick` (explicit pid, exact root, deepest root containing the target, then newest focus/start). Protocol: one JSON `Request{V:1, Cmd, Path, Line, Col, EndLine, Base, Uncommitted, From}` and one `Reply{OK, Error, Message, Where}` per connection. `ServeListener` answers `ping`/`where` from the presence store directly and hands `open`/`review`/`diff` to the UI as `RequestMsg{Req, Reply, Deadline}` via `p.Send`, replying `deck is busy: editor open` after `navTimeout` (2 s; `ExecProcess` blocks the loop) — the app drops the late message by `Deadline`. `ParseTarget` (trailing `:l`, `:l:c`, `:l-e` only), `HeldMessage`, and the embedded agent `guide.md` (`Guide`, `InstallClaudeSkill`).
- `internal/launch` — pure `Detect(getenv, goos)` (Orca, cmux, Paradev, tmux, Zellij, WezTerm, kitty, then Ghostty/iTerm2/Terminal on darwin, Alacritty) and `Command(target, mode, dir, deckBin)` (split/tab/window with per-environment fallbacks; AppleScript via `osascript -e`; `cd '<dir>' && exec '<deck>'` where there is no cwd flag), `Start` through the `execCommand` seam, `Hint` for the manual fallback.

- `internal/lsp` — in-house LSP client, standard library only (no Bubble Tea, no other `deck/internal` import; `TestImportsStandardLibraryOnly` enforces it). `conn.go` is JSON-RPC with Content-Length framing; `registry.go` holds `DefaultSpecs()` (csharp-ls, gopls, typescript-language-server, pyright, rust-analyzer, bash-language-server, lua-language-server, yaml-language-server, vscode-json-language-server; each with a `Language` name and an `Install` argv whose first element is the installer, `InstallHint()` is that argv joined), `MergeSpecs` for config overrides, `FindRoot` (markers in priority order, walking up to the git top level / `$HOME`, never `/`) and `LookupBinary` (`PATH`, then `~/.dotnet/tools`, `~/go/bin`, `~/.cargo/bin`, `$GOPATH/bin`, Homebrew; results cached, `Forget(name)` drops them). A missing binary fails once and is not retried until `Retry(name)` (forgets the failure and the cached lookup, emits an idle status) — `Install(ctx, name)` runs `InstallCommand(name)` through `RunInstall` (own process group, no stdin, `HOMEBREW_NO_AUTO_UPDATE`; cancelling kills the group; `WithInstaller` is the seam) and retries on success, and `Shutdown` cancels running installs. A crashed server restarts once. Clients track Starting → Indexing → Ready from `$/progress` (or 2 s without progress), keep a 30-document didOpen LRU, and resync on mtime change or `Reload`. `Events()` carries `StatusEvent`/`DiagnosticsEvent`/`LogEvent`/`ShowMessageEvent` through a 256-entry queue that drops logs first. `Shutdown(ctx)` sends shutdown/exit, then kills the process group (servers start with `Setpgid`). Columns stay in the server's negotiated encoding; convert with `RuneToUnits`/`UnitsToRune`/`ByteToUnits`/`UnitsToByte`. Tests drive `lsptest`, an in-process fake server over `net.Pipe`, through the injectable `Starter`; `integration_test.go` runs real gopls when installed.

### Agent support

`main` (`agent.go`) listens on the control socket before `p.Run`, registers the instance after the program exists, publishes presence through `app.Model.WithAgent(store, controlDir)` and, with `agent.claude`, starts the IDE bridge before the program using an atomic program ref for `Send` (`WithIDE`). In the app, `Update` wraps `update` and publishes `snapshot()` after every message (Files: viewer cursor/selection, rendered-markdown section, directory; Git: `git.Pane.Spot()`), stores LSP diagnostics and `Touch`es the sidecar on `tea.FocusMsg`. `control.go` applies requests (`files.AgentOpen` pushes the jump history first, so `ctrl+o` undoes agent jumps; review/diff send `git.ReviewMsg`) with a `<From> → rel:line` toast, or holds the latest one while capturing (status `Claude: rel:line · ⌥j`). `watch.go` polls every `agent.watch_ms`: the open file's mtime^size (→ `files.ReloadFileMsg`, a deleted file shows `file deleted`) and, every second tick with one in flight at most, `git.Fingerprint` (porcelain v2 plus each changed path's mtime/size, so re-edits count) → `git.Refresh` + `files.ReloadCurrent`; a status slower than 1 s backs off to 10 s once. The viewer has `v`/`V` selection (inclusive cursor, mouse drag, shift+click; `y`/`Y` copy text / `rel:l1-l2`; `@` emits `ui.MentionMsg`; `v` on rendered markdown switches to source at the section). The Git tab's Review mode (`v`) lists the branch's commits and files against `merge-base <base> HEAD` (`ResolveBase`: `--base`, `git.review_base`, origin's HEAD, origin/main, origin/master, main, master; falls back to uncommitted with a reason), per-file viewed ticks in `<GitDir>/deck/review.json` keyed by blob hash (cleared when content changes, fresh per base), `u` uncommitted-only, `n` next unviewed; every single-file diff has a line cursor (`diffRowToFile` maps rows to new-side lines) with `v` select, `enter` → `ui.ShowFileMsg`, `e` at the cursor line and `@`.

### Streaming pattern (used by `runner`)

The process goroutine pushes `chunk`s onto a buffered channel and the exit onto a second one. `proc.next()` returns a `tea.Cmd` that blocks for the first chunk, then drains up to 256 lines or 16 ms into one `OutputMsg`; once the line channel closes it returns the `ExitMsg`, then nil. After each `OutputMsg` the pane returns `proc.next()` again, so Bubble Tea keeps a single read pending.

### Testing notes

Tests sit next to the code they cover. Panes are driven by calling `Update` with `tea.KeyMsg`/`tea.MouseMsg` and running returned commands synchronously; never a `tea.Program`. Cross-package checks use small exported accessors (`git.Pane.Reloads`, `files.Model.SelectedPath`/`ViewerLoc`) because `export_test.go` seams are invisible to other packages. The invariant tests are `TestFrameFitsTerminal` (`internal/app/layout_test.go`) and `TestAsyncRoutedWhileOtherTabActive` / `TestRunnerOutputRoutedWhileOtherTabActive` (`internal/app/app_test.go`, the latter runs a real `sh` task). The `aicommit`, `httpc`, `git` and `config` packages have substantial unit coverage of their pure helpers. `internal/git/integration_test.go` exercises the real `git` CLI against temp repos (isolated from the user's global config) — needs `git` on `PATH`; git pane tests drive real repos through a `settle` helper that runs returned commands and feeds routed results back, and `TestNewPaneRunsNoGit` counts `runGit` calls through the `execCount` seam. Agent tests: `internal/control` and `cli_agent_test.go` run real Unix sockets in `os.MkdirTemp("", "dk")` dirs (never `t.TempDir()` — macOS's socket-path limit); `internal/ide` dials the bridge with a real WebSocket client against a temp `ConfigDir`; app agent tests use `agentFixture`/`drive` (runs commands with a 300 ms cap so ticks don't block) in `presence_test.go`; review tests drive real temp repos (`reviewRepo`). Run `go test -race ./internal/lsp/...` after touching `internal/lsp`, `go test -race ./internal/viewer/ ./internal/files/` after touching the viewer, and `go test -race ./internal/runner` after touching the runner; its process tests run real `sh`/`sleep` pipelines with unique `sleep 30.NNNNNN` markers and check `pgrep` afterwards. `go test -bench ViewerView ./internal/viewer/` guards render cost, `-bench TreeFlatten ./internal/files/` the tree (10k nodes).
